## ТЕКУЩАЯ РАБОТА: №30c (мелочь из бэклога, «простая», автослияние: да)
Дефект (из бэклога): CSS кнопок сообщения (.message-edit и .message-delete, style.css около строк 859–860 и 921–922) показывает их по .message-row:focus-within внутри @media (hover: hover): после клика мышью по кнопке она остаётся видимой, пока фокус на ней (нарушает правило процесса: для показа скрытых кнопок использовать :focus-visible). Исправление: убрать две строки .message-row:focus-within … из медиа-блоков и добавить правило вне медиа-блока: .message-edit:focus-visible, .message-delete:focus-visible { opacity: 1; pointer-events: auto; } (кнопки с opacity 0 остаются достижимыми по Tab, так как opacity не отключает фокус; на устройствах без hover с клавиатурой кнопка тоже покажется). Один e2e в chat.spec.ts (мышь вне строки, Tab до кнопки, проверка computed opacity через getComputedStyle: edit "1" на фокусе, после следующего Tab на delete: delete "1", edit "0"); числа после: crypto 53, server 152, web 276, e2e 67. Проверку мыши (клик по кнопке, закрытие подтверждения, увод мыши: кнопка пропадает) делает владелец вручную (в e2e надёжно не воспроизвести).
