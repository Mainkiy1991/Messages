## НАХОДКА: контакты между устройствами не обновляются без F5
Это НЕ регрессия: живой синхронизации контактов никогда не было. Клиент (chat-controller.ts, loadContacts) читает зашифрованную книгу один раз при старте (флаг contactsLoaded) и не перечитывает при переподключении; у сервера нет кадра WebSocket про контакты, есть только GET и PUT /contacts с номером версии. Данные не теряются: при конфликте версий действие применяется заново к свежей книге. План: ТЗ №37a (кадр contacts_updated с номером версии без содержимого + перечитывание книги, плюс при возврате связи), см. PROFILE-DESIGN.

## ТЕКУЩАЯ РАБОТА: этап №37 «Профиль» (docs/PROFILE-DESIGN.md)
Схема: профиль (имя до 64, «О себе» до 200) шифруется профильным ключом P (HKDF от ключа истории, один на все мои устройства); собеседнику выдаётся «обёртка» с P, зашифрованная общим секретом пары (X25519 + HKDF); на сервере блок профиля и обёртки, посторонним 404; кадры profile_updated и contacts_updated без содержимого. Отказались от профиля внутри сообщений (засоряет историю, счётчики, очистку чата). План ТЗ (все «сложные»): №37a синхронизация контактов, №37b крипто профиля, №37c сервер (миграция 013: сначала владелец применяет к боевой базе, потом Merge), №37d клиентские данные, №37e окна (общий механизм, полноэкранное меню профиля, «Назад» по шагам; проверка на телефоне), №37f показ чужого профиля.
