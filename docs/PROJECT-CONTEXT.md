## НАХОДКА: контакты между устройствами не обновляются без F5
Разбор по коду (28 ноября, main после PR #97): это НЕ регрессия, живой синхронизации контактов никогда не было. Клиент (chat-controller.ts, loadContacts) загружает зашифрованную книгу один раз при старте (флаг contactsLoaded) и не перечитывает её при переподключении; у сервера нет кадра WebSocket про контакты (кадры: message_updated, message_deleted, messages_erased, conversation_cleared и др.), есть только GET и PUT /contacts с номером версии. Данные при этом не теряются: если на «отставшем» устройстве изменить контакт, действие применяется заново к свежей книге (конфликт версий), удалённый на другом устройстве контакт не возвращается.
План: сделать в этапе «Профиль» (там своё имя и «О себе» тоже лежат в этой книге и должны доезжать на другие устройства): после записи книги сервер шлёт остальным сокетам этого аккаунта короткий кадр с новым номером версии (без содержимого), клиент при несовпадении версии перечитывает книгу; плюс перечитывание при возврате связи. Это «сложное» ТЗ (сервер, протокол, клиентское состояние); в проект «Профиль» включить отдельным пунктом и показать владельцу простым примером. Выбор сделан техруком; владельцу вопросов нет.
