## ЛОКАЛЬНЫЙ POSTGRESQL В ПЕСОЧНИЦЕ ТЕХРУКА (проверено 28 ноября)
apt-get update; apt-get install -y postgresql (16); pg_ctlcluster 16 main start; su postgres -c "psql -c \"ALTER USER postgres PASSWORD 'pw'\" -c \"CREATE DATABASE messages_test\""; затем export TEST_DATABASE_URL=postgres://postgres:pw@localhost:5432/messages_test; corepack pnpm --filter @messages/crypto build и @messages/shared build; cd apps/server && corepack pnpm exec vitest run (всё), либо vitest run src/app.test.ts -t "<регулярка>". Фильтр -t сопоставляется с названием теста: для мутаций брать регулярку по ключевым словам всех нужных названий и сверять число выбранных тестов. Клиентские мутации: клонировать репозиторий (git clone --depth 1), git fetch ветки PR, corepack pnpm install --frozen-lockfile, собрать crypto и shared, затем cd apps/web && corepack pnpm exec vitest run src/lib/chat-controller.test.ts; код мутировать через sed/python, возвращать копией из /tmp.
