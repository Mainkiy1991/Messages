## ЛОКАЛЬНЫЙ POSTGRESQL В ПЕСОЧНИЦЕ ТЕХРУКА (проверено 28 ноября)
apt-get update; apt-get install -y postgresql (16); pg_ctlcluster 16 main start; su postgres -c "psql -c \"ALTER USER postgres PASSWORD 'pw'\" -c \"CREATE DATABASE messages_test\""; затем export TEST_DATABASE_URL=postgres://postgres:pw@localhost:5432/messages_test; corepack pnpm --filter @messages/crypto build и @messages/shared build; cd apps/server && corepack pnpm exec vitest run (всё), либо vitest run src/app.test.ts -t "<регулярка>". Внимание: фильтр -t сопоставляется с названием теста, тест может не попасть в выборку (так «enforces the per-owner share limit…» не попал под -t "profile"): для мутаций брать регулярку по ключевым словам обоих названий и сверять число выбранных тестов с ожидаемым.
