## СТАТУС (24 ноября 2026)
- В main влиты PR до #80 включительно. №31a/b/c (общий PIN) слиты, но проект отменён: PIN на каждом устройстве свой (решение владельца 24 ноября, вариант A). Причина: закрытое или заблокированное устройство не может принять новый PIN без ввода прежнего (ключи на нём заперты прежним PIN, сервер их не видит); обход требовал бы хранить на сервере копию ключей под PIN, это недопустимо. Подробности и урок: docs/PIN-SYNC-DESIGN.md.
